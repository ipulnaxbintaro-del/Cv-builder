CV BUILDER PWA — iPhone

Ini adalah versi PWA yang bisa dipasang ke Home Screen iPhone.

PENTING:
- Safari iPhone tidak mengizinkan file HTML lokal biasa dipasang sebagai PWA.
- Agar tombol "Add to Home Screen" dan service worker bekerja, folder ini harus dibuka melalui alamat HTTPS/localhost.
- Jika tidak ingin hosting publik, jalankan folder ini di komputer dengan server lokal; namun iPhone harus berada pada jaringan yang sama.
- Generator PDF berjalan di browser dan menghasilkan PDF A4.

Cara paling praktis:
1. Upload folder ini ke hosting statis apa pun yang menyediakan HTTPS.
2. Buka URL-nya di Safari iPhone.
3. Share -> Add to Home Screen.
4. Buka aplikasi dari Home Screen.
5. Isi CV -> Generate PDF -> file PDF langsung dibuat.

Versi ini sengaja tidak memakai backend: data CV tetap di perangkat/browser.
